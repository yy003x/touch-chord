TouchChord — 三指触摸保持 Command

1. 将 TouchChord.app 拖到 Applications 文件夹。更新前先从菜单栏退出旧版。
2. 从“应用程序”打开 TouchChord，不要直接从 DMG 运行。
3. 如 macOS 提示无法验证开发者，先尝试打开，再到“系统设置 → 隐私与安全性”
   为 TouchChord 点击“仍要打开”，由本人确认。无需上架 App Store。
4. 在“隐私与安全性 → 辅助功能”和“输入监控”中添加并开启
   /Applications/TouchChord.app。权限修改可能要求退出并重新打开应用。
5. 重新打开 TouchChord，点击“重新检查并连接”。先抬起全部手指，再放三指测试。

三指或更多时保持 ⌘；少于三指立即释放。Escape 可紧急释放。
菜单栏始终显示固定尺寸的 ⌘，模拟按住时反白，不显示 ON。
显示／隐藏由“系统设置 → 菜单栏 → 允许在菜单栏显示 → TouchChord”统一管理。
应用里的“系统菜单栏设置…”可直达该页面。隐藏后仍在后台运行，
重新打开 /Applications/TouchChord.app 可进入设置；恢复图标请开启系统的 TouchChord 开关。
如有旧路径的登录启动项，请关闭旧项，从安装后的 TouchChord 设置重新开启。

本包使用固定本地自签名证书，未经 Apple 公证，不代表 Apple 认证。
“仍要打开”不代替辅助功能或输入监控授权。后续版本使用同一证书和应用身份，
不再随代码更新更换身份；系统仍可能在撤销权限、迁移设备或安全策略变化后要求授权。

仅当前 Apple Silicon / macOS 开发设备做过核心触摸及物理 Command 共存测试。
使用 MultitouchSupport 私有 API，系统升级后需要重新验证。
如输入状态异常：先抬起手指，按下并松开物理 Command，再退出 TouchChord。
进程崩溃或被强制结束时无法保证执行清理。
