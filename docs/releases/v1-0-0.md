# TouchChord · 和弦 v1.0.0

首个 GitHub 发布基线：三指及以上触摸内置触控板时保持 Command，少于三指立即释放。

正式发布版本：1.0.0 / build 7。

## 本版内容

- 应用由 TriKey 更名为 TouchChord，新增深蓝底、三个触点与 ⌘ 的应用图标。
- 保留既有触摸阈值、激活防抖、物理 Command 来源管理、异常释放和原生菜单栏功能。
- 保留 Bundle ID `local.trikey.app`、固定签名身份及偏好键，更名后本机授权继续有效。
- 提供 DMG、完整签名应用 ZIP、SHA-256 清单和恢复脚本。
- 改善授权跳转后的窗口返回：设置打开期间使用普通应用模式，关闭后回到菜单栏模式；冷启动首次跳转仍有残留问题。

## 安装与恢复

Apple Silicon 用户下载 `touch-chord-1.0.0-arm64.dmg`，退出旧版后安装至 `/Applications/TouchChord.app`。
本包采用本地自签名证书，未经 Apple 公证；互联网下载后的首次安全确认需由本人完成。
辅助功能和输入监控权限仍需按系统要求授予。

恢复本版时，将 ZIP、`sha256sums.txt`、`restore-release.sh` 放入同一目录，执行：

```sh
bash restore-release.sh . --verify-only
bash restore-release.sh .
```

脚本正常退出当前应用、备份替换前应用，再恢复原签名二进制；无需构建、重签或清理权限。
完整说明见 [恢复文档](https://github.com/yy003x/touch-chord/blob/v1.0.0/docs/recovery.md)。

## 本机验证与边界

- 11 项 XCTest 通过；Release 构建、固定签名、DMG 校验和、挂载后应用比对通过。
- 更名安装及实际 ZIP 恢复后，两项权限保留，内置触控板连接正常，登录启动指向新安装路径。
- 用户已在新版完成三指 Command+A 全选及抬指后普通输入，确认两项正常。
- 原有核心输入逻辑已在当前设备进行真实触摸和物理 Command 交错测试；详细证据见验证文档。
- 私有 `MultitouchSupport` API 只在当前 Apple Silicon / macOS 27.0.1 设备验证。
- 关闭系统设置后的窗口返回问题已通过两个入口各三轮真实桌面回归及用户复测。
- 发布后从 GitHub 重新下载并完成本机重装，版本、签名、两项权限和触控板连接回读正常。
- 冷启动后的首次授权跳转复测仍发现窗口被其它应用遮挡；重新激活窗口后连续回归通过，根因尚未完全定位。
- 菜单栏图标曾偶发缺失，重启可恢复，根因未确定。
- 长时间运行、休眠、Secure Input、其它 macOS 和 Intel 兼容性仍未完成全面验收。

`v1.0.0` 是可恢复的使用基线，不表示所有已知问题已修复，也不承诺崩溃或强制结束时绝不卡键。
后续功能使用新版本，不覆盖此标签和附件。
