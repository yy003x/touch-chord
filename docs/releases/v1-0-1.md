# TouchChord · 和弦 v1.0.1

发布版本：1.0.1 / build 14，适用于 Apple Silicon。

## 本版内容

- 精确匹配 2、3、4 指触摸，默认分别为 Control、Command、Option。每档可选 Command、Option、Control、Shift、Return、Esc 或“不触发”。
- 修饰键保持到换档或抬起；Return、Esc 每次稳定触摸只发送一次，保持触摸不连发，同名物理键按住时跳过。
- 新增系统“轻点来点按”检查。启用前须关闭该设置；0、1、5 指及以上释放模拟键，换档先释放再防抖。
- 菜单栏使用固定尺寸的触控板图标，并显示当前按键符号，适配明暗外观。
- 修复排队的 Return/Esc 被后续修饰键档位改写标志的问题。
- 遗留按键恢复先于触摸激活门禁，确认释放后再连接触控板；超时保留恢复记录。
- 设置验证脚本在失败时恢复原映射和持久值，并回读核对；无法完整恢复时报告残留风险。

## 安装与回退

下载 `touch-chord-1.0.1-arm64.dmg`，退出旧版后将 TouchChord 拖入 Applications，
从 `/Applications/TouchChord.app` 启动。也提供相同签名应用的 ZIP、安装说明和 SHA-256 清单。

保留 Bundle ID `local.trikey.app`、固定签名身份与已有偏好。普通更新无需主动重置权限；
辅助功能、输入监控以及首次下载后的系统安全确认仍按 macOS 提示由本人完成。
本包采用本地自签名证书，未经 Apple 公证。

从 v1.0.0 升级后，三指加到四指会切换为四指映射，五指会释放；不再沿用“三指以上都保持 Command”。
两指手势可能受到默认 Control 映射影响，可将两指设置为“不触发”。

需要回退时先正常退出；异常情况下先抬起触控板并按下、松开受影响的物理键。
使用冻结的 [v1.0.0 Release](https://github.com/yy003x/touch-chord/releases/tag/v1.0.0)
及其 [恢复说明](https://github.com/yy003x/touch-chord/blob/v1.0.0/docs/recovery.md)。
旧版恢复脚本只校验 v1.0.0 附件，不能与本版 ZIP 混用；旧版也不清理新增修饰键的恢复记录。
